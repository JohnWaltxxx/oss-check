# Contributing to oss-check

Thanks for helping improve `oss-check`.

## Local setup

```bash
python -m pip install -e .
python -m unittest discover -s tests -v
```

## Pull requests

1. Keep the project dependency-free unless there is a strong reason not to.
2. Add or update tests for behavior changes.
3. Explain the user problem and the trade-offs in the pull request description.
4. Keep commits focused and documentation current.

Please do not include real credentials, private repository contents, or other sensitive data in issues and pull requests.

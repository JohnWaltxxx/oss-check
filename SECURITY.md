# Security policy

## Reporting a vulnerability

Please do not publish credentials, private repository contents, or an exploitable vulnerability in a public issue. Contact the maintainers privately through the contact method listed on the project's GitHub profile.

Include the affected version, reproduction steps, and an assessment of impact. Reports without sensitive details are easier to investigate safely.

`oss-check` is a repository hygiene helper, not a complete security scanner. Its secret checks are heuristic and should not replace dedicated security tooling.
